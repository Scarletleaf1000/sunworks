# Sunworks
[![Modrinth](https://img.shields.io/modrinth/dt/sunworks?logo=modrinth&label=Modrinth&color=00AF5C)](https://modrinth.com/mod/sunworks)
[![Discord](https://img.shields.io/discord/1537310030645436446?logo=discord&label=Discord&color=5865F2)](https://discord.gg/NrMwNE72qZ)
[![GitHub Repo](https://img.shields.io/github/stars/ScarletLeaf1000/sunworks?logo=github&label=Stars&color=181717)](https://github.com/ScarletLeaf1000/sunworks)

Sunworks is a minecraft tech mod that allows you to power machines with the sun.
However it doesn't just add solar panels, it also adds the ability to collect power directly from the sun itself.

Sunworks is currently in early development and is not yet ready for release.
Many features have yet to be added.

## Features
 - Solar Panels
 - Multiblock Power Generation Structures
 - Many Ores and Crafting Materials

## Dependencies/Compatibility
- **JEI**: Sunworks has full [JEI](https://modrinth.com/mod/jei) compatibility
- **Ponder**: Sunworks is dependent on the [Ponder](https://github.com/Creators-of-Create/Ponder) library made by the team of [Create](https://modrinth.com/mod/create). The library is embedded in the mod's jar so no additional mod is required
- **Mekanism**: Sunworks has been tested with [Mekanism](https://modrinth.com/mod/mekanism) and works well, however, no additional compatibility exists between the mods.
